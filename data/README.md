# Reference adjacency

The Abilene and Polska node names and undirected edges are extracted from the SNDlib versions archived by [TopoHub](https://github.com/piotrjurkiewicz/topohub). The source URL and exact upstream blob SHA are recorded in each JSON file. Abilene has 12 nodes and 15 edges. Polska has 12 nodes and 18 edges. The simulator adds separate classical edges and generates all physical and workload parameters. It does not use the original edge lengths or demand matrices.

- Piotr Jurkiewicz. 2023. TopoHub: A repository of reference Gabriel graph and real-world topologies for networking research. SoftwareX 24, 101540. [DOI](https://doi.org/10.1016/j.softx.2023.101540).
- Sebastian Orlowski, Roland Wessäly, Michał Pióro and Artur Tomaszewski. 2010. SNDlib 1.0—Survivable Network Design Library. Networks 55(3), 276–286. [DOI](https://doi.org/10.1002/net.20371).
